# Python Grundkurs

Willkommen im Kurs! Hier findest du alle Kursmaterialien nach folgendem Schema:
- **ch01, ch02, ...**: Die Kapitel (**ch**apters) des interaktiven Lehrbuchs für diesen Kurs. In der Regel behandeln wir zwei Kapitel pro Sitzung.
- **ex01, ex02, ...**: Die Hausaufgaben (**ex**ercises) für den Kurs, die eigenständig zu bearbeiten sind. Jede Woche gibt es eine neue Aufgabenstellung.
- **a01, a02, ...**: Die Code-Analysen (**a**nalysis), also Beispielprogramme, die am Ende jeder Sitzung besprochen werden.
